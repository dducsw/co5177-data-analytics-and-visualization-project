# Tabular Data: Bank Account Fraud Detection

Bài tập lớn phân tích và mô hình hóa dữ liệu dạng bảng (Tabular Data).

- **Tập dữ liệu**: [Bank Account Fraud Dataset Suite (NeurIPS 2022)](https://www.kaggle.com/datasets/sgpjesus/bank-account-fraud-dataset-neurips-2022)
- **Bài toán**: Nhận diện đơn mở tài khoản ngân hàng gian lận (Binary Classification: Fraud vs. Legitimate).
